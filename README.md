# Nexora – Project Management Dashboard

Nexora is a modern and responsive **Project Management Dashboard** built with React. It provides a clean interface for managing projects, tasks, team members, analytics, schedules, and workspace settings.

This project was created as a frontend portfolio and internship project to demonstrate practical React development, responsive UI design, reusable components, routing, filtering, and dashboard layouts.

### 📊 Dashboard
- Total projects overview
- Active tasks
- Team members
- Total budget
- Project activity overview
- Tasks by status
- Quick project creation
